# Архив: варианты использования по старой версии ТЗ

Диаграммы в этой папке сделаны по старой версии ТЗ и в проекте не используются.
Они противоречат ТЗ v11: в них есть регистрация и вход, администратор, загрузка
расписания администратором, автоматический планировщик импорта из ОРИОКС
и «горизонт планирования».

Актуальные варианты использования — `docs/uml/puml/UC-01_zadachi.puml`
и `docs/uml/puml/UC-02_kalendar_ii.puml`.
