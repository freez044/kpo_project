# UML-диаграммы Adaptive AI Planner (по ТЗ v11)

| Файл | Что внутри |
|---|---|
| `Диаграммы_последовательностей_и_активности.pdf` | SD-01–SD-12 и AD-01–AD-06, по одной на страницу |
| `Описание_диаграмм_последовательностей_и_активности.docx` | Краткое описание каждой диаграммы и таблица «ФТ → диаграммы» |
| `uml class.docx` | Диаграмма классов CL-01 и описание классов |
| `png/` | Все диаграммы картинками |
| `puml/` | Исходники PlantUML. `style.iuml`, `seqhead.iuml` и `CL-01_entities.iuml` держать рядом |
| `legacy/` | Архив: варианты использования по старой версии ТЗ, в проекте не используются |

Варианты использования по ТЗ v11 — `UC-01_zadachi` (задачи, цели и данные пользователя)
и `UC-02_kalendar_ii` (календарь, нагрузка и ИИ-ассистент).

Перерисовать: `java -DPLANTUML_LIMIT_SIZE=16384 -jar plantuml.jar -tpng -o ../png puml/*.puml`
или плагин PlantUML в VS Code / IntelliJ.

- UC — варианты использования
- SD — последовательности
- AD — активности
- CL — классы
- CD — компоненты
- LD — уровни архитектуры

Номера ФТ в заголовках диаграмм соответствуют ТЗ v11 (`docs/ТЗ_Adaptive_AI_Planner_v11.docx`).

Классы описаны один раз в `puml/CL-01_entities.iuml`. Этот файл подключают и диаграмма классов CL-01,
и модель данных `database/data_model.puml`, поэтому сущности в них всегда совпадают.
Имена классов, полей и операций на SD-диаграммах совпадают с `docs/storage/db.ts`.
