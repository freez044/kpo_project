# UML-диаграммы Adaptive AI Planner (по ТЗ v10)

| Файл | Что внутри |
|---|---|
| `Диаграммы_последовательностей_и_активности.pdf` | SD-01–SD-13 и AD-01–AD-06, по одной на страницу |
| `Описание_диаграмм_последовательностей_и_активности.docx` | Краткое описание каждой диаграммы и таблица «ФТ → диаграммы» |
| `png/` | Все диаграммы картинками, включая UC-01, UC-02, CD-01, LD-01 |
| `puml/` | Исходники PlantUML. `style.iuml` и `seqhead.iuml` держать рядом |

Перерисовать: `java -jar plantuml.jar -tpng puml/*.puml`
или плагин PlantUML в VS Code / IntelliJ.

- UC — варианты использования
- SD — последовательности
- AD — активности
- CD — компоненты
- LD — уровни архитектуры

Номера ФТ в заголовках диаграмм соответствуют ТЗ v10 (`docs/ТЗ_Adaptive_AI_Planner_v10.docx`).
