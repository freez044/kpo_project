# Локальное хранилище (IndexedDB через Dexie)

`db.ts` — прототип браузерного хранилища данных по ТЗ v11. Актуальная серверная [модель данных v12](../../database/data_model.puml) отличается: IndexedDB теперь предполагается только для копии канбан-доски и календаря в режиме просмотра без сети.
Имена типов и полей совпадают с классами диаграммы CL-01.

Что внутри:

- 10 таблиц: профиль, категории, цели, задачи, личные события, интервалы задач, учебные занятия, учебные задания, файлы, предложения ИИ;
- каскадные удаления в транзакциях (ФТ-09, ФТ-13, ФТ-16, НД-03) и подсчёт удаляемых данных для окна подтверждения;
- проверки данных (НД-04);
- резервная копия: файл проверяется целиком до изменения данных, при ошибке данные возвращаются из снимка (ФТ-03–ФТ-05);
- история запросов к ИИ со статусами PENDING / ACCEPTED / EDITED / REJECTED и выгрузкой в JSON (ФТ-40).

`db.test.ts` — 14 тестов: удаления, проверки, календарь и пересечения, файлы, история ИИ, резервная копия (в том числе обрезанный и чужой файл). Код и тесты проверены на Dexie 4.4.1 и fake-indexeddb 6.2.6; все тесты проходят.

Файлы лежат здесь до создания каркаса фронтенда; затем их нужно перенести
в `frontend/src/db/` (задача «Подключить хранилище IndexedDB»).

Зависимости: `npm i dexie dexie-export-import`, для тестов `npm i -D vitest fake-indexeddb`.
