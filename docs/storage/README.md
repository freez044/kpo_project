# Локальное хранилище (IndexedDB через Dexie)

`db.ts` — схема хранилища и функции работы с данными по ТЗ v10:
10 таблиц, каскадные удаления в транзакциях (НД-03), проверки данных (НД-04),
резервная копия с откатом при ошибке (ФТ-03, ФТ-04), история запросов к ИИ (ФТ-41).

Файл лежит здесь до создания каркаса фронтенда; затем его нужно перенести
в `frontend/src/db/` (задача «Подключить хранилище IndexedDB»).

Зависимости: `npm i dexie dexie-export-import`.
Код проверен компилятором TypeScript, но не запускался на настоящем Dexie —
первым делом прогнать `tsc` и проверить удаление задачи с файлами и восстановление из копии.
