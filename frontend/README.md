# Интерфейс Adaptive AI Planner

React, TypeScript и Vite. Запуск из папки frontend: `npm install`, затем `npm run dev`.
Нужен backend на 127.0.0.1:8000. Полная инструкция — [LOCAL_START.md](../LOCAL_START.md).
Проверка: `npm run build`.

## Структура команды

Реализация размещена в каркасе, добавленном Enkukee:

- `components/Sidebar.tsx`, `Header.tsx`, `Modal.tsx` — навигация, шапка и общее модальное окно с соответствующими CSS.
- `pages/Dashboard.tsx` — главная страница; `pages/Tasks.tsx` — список и фильтры задач.
- `pages/Calendar.tsx`, `Assistant.tsx` — текущие заглушки этих разделов.
- `services/api.ts` — HTTP-запросы, обновление токена, повтор после 401 и защита от смены аккаунта в другой вкладке.
- `services/auth.ts` — входная точка авторизации; `services/AuthProvider.tsx` — контекст сессии и формы входа/регистрации.
- `types/task.ts`, `types/user.ts` — общие типы текущего локального API.
- `styles/global.css`, `variables.css` — общие адаптивные стили и переменные оформления.
- `Planner.tsx` — состояние приложения и подключение страниц к данным; страницы получают данные и обработчики через props.
- `tasks.tsx` — карточки и формы задач; `Kanban.tsx`, `Orioks.tsx`, `OrioksPlanning.tsx` — действующие модули канбана и ОРИОКС.

`auth.tsx` и `styles.css` оставлены как совместимые входные точки для старых импортов.
Пустые страницы Analytics, Feedback и Profile сохранены для дальнейшей работы, но ещё не подключены.
`services/storage.ts` зарезервирован под копию для просмотра без сети; сохранение серверных данных в браузер пока не реализовано.

## Границы локальной версии

Аккаунты и задачи сохраняются через backend в локальную SQLite. Цели временные; календарь и ИИ пока не реализованы.
Типы описывают фактический локальный API: категория задачи пока является текстом, не categoryId общей PostgreSQL-схемы.
Командные контракты в docs/contracts.md не менялись. Подключение общего слоя данных остаётся отдельным этапом.
Токены доступа находятся в памяти API-клиента, refresh-токен — в HttpOnly cookie; ключи ОРИОКС остаются на сервере.
