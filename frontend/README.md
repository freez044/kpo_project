# Локальный интерфейс Adaptive AI Planner

Стартовая главная страница на React, TypeScript и Vite. Backend и PostgreSQL для её запуска не нужны.

## Запуск

Установите Node.js 22.12+ (или 20.19+). Откройте терминал в этой папке:

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite, обычно http://127.0.0.1:5173. Для остановки нажмите Ctrl+C.

Если используете pnpm, вместо npm install выполните pnpm install, затем pnpm dev. pnpm-lock.yaml фиксирует зависимости для этого варианта.

## Проверка сборки

```sh
npm run build
npm run preview
```

## Что работает

- Главная: план на сегодня, счётчики выполнения, просроченные задачи.
- Фильтрация по учебным и личным задачам, создание задач и отметка выполнения.
- Создание целей и просмотр списка целей.
- Переходы к заготовкам календаря и ИИ-ассистента.
- Адаптивная вёрстка для телефона и компьютера.

Это интерфейсный прототип: задачи и цели хранятся только в памяти React и сбрасываются после обновления страницы. Начальные данные демонстрационные. Запросов к API, авторизации, базы данных, настоящего календаря и интеграций пока нет. Данные задач вынесены в main.tsx; при подключении backend их нужно заменить запросами к API, а не считать текущий прототип постоянным хранилищем.
