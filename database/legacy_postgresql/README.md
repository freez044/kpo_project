# Архив: схема PostgreSQL

Эти SQL-скрипты относятся к ранней версии проекта, где данные хранились на сервере в PostgreSQL
и были учётные записи пользователей. По ТЗ v11 все данные хранятся в браузере (IndexedDB),
сервер данных не хранит, поэтому скрипты в проекте не используются.

Актуальная модель данных — [`../data_model.md`](../data_model.md), её реализация — [`docs/storage/db.ts`](../../docs/storage/db.ts).

Скрипты оставлены для истории и не обновлялись: в них есть таблица рабочих сессий и поле
`estimated_duration_minutes`, которых в актуальной модели нет.
